## What is it?

VTR Press is an open-source publishing engine built around structured Markdown manuscripts.

It provides a shared document model and rendering infrastructure for producing professional PDF and EPUB publications, with support for both books and technical documents.

## Why?

Publishing should not require rewriting a manuscript for every output format. VTR Press keeps content, document structure and presentation concerns separate so that the same source can support different publication outputs.

The project also makes the publishing process repeatable and maintainable rather than treating each book as a one-off production exercise.

## Current status

The v2.0 architectural foundation is complete. The project is now in its post-v2 feature stage, with ongoing work focused on incremental publishing and print-layout improvements.
